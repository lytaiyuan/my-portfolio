# Hero 图片文件夹

这个文件夹用于存放网站的hero背景图片。

## 使用方法

1. **添加新图片**: 直接将jpg/JPG格式的图片文件放入此文件夹
2. **更新配置**: 运行 `npm run update-hero` 来更新配置文件
3. **自动随机**: 每次刷新页面时，系统会自动从配置文件中随机选择一张图片作为hero背景
4. **命名规则**: 文件名可以是任意名称，支持`.jpg`和`.JPG`扩展名

## 技术特性

- **配置文件驱动**: 通过hero.json配置文件管理图片列表
- **格式支持**: 同时支持.jpg和.JPG扩展名
- **智能回退**: 如果配置文件加载失败，会使用预定义的图片列表作为后备
- **实时更新**: 更新配置文件后，刷新页面即可看到新图片

## 管理方法

### 添加新图片
1. 将jpg/JPG图片放入此文件夹
2. 运行更新脚本：`npm run update-hero`
3. 刷新网站页面

### 删除图片
1. 从文件夹中删除不需要的图片
2. 运行更新脚本：`npm run update-hero`
3. 刷新网站页面

### 手动编辑配置
您也可以直接编辑 `public/hero.json` 文件来管理图片列表。

## 注意事项

- 支持jpg和JPG格式的图片（大小写不敏感）
- 图片会自动随机展示，无需手动配置
- 添加或删除图片后，需要更新配置文件
- 建议图片尺寸保持一致，以获得最佳的视觉效果
- 配置文件会自动包含文件夹中的所有jpg/JPG图片

## 测试功能

您可以使用 `test_hero_dynamic.html` 页面来测试功能：
- 查看当前配置的所有图片
- 测试随机选择功能
- 验证配置文件是否正确加载
