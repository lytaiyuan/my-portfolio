# Hero 图片文件夹

这个文件夹用于存放网站的hero背景图片。

## 使用方法

1. **添加新图片**: 直接将jpg/JPG格式的图片文件放入此文件夹
2. **自动随机**: 每次刷新页面时，系统会自动从文件夹中随机选择一张图片作为hero背景
3. **命名规则**: 文件名可以是任意名称，支持`.jpg`和`.JPG`扩展名

## 当前图片

- `hero.jpg` - 主要hero图片
- `hero.1756305625.bak.jpg` - 备份图片
- `2.jpg` - 额外hero图片
- `IMG_8176.JPG` - 大写JPG图片1
- `DSC09073.JPG` - 大写JPG图片2

## 注意事项

- 支持jpg和JPG格式的图片（大小写不敏感）
- 图片会自动随机展示，无需手动配置
- 添加新图片后，刷新页面即可看到效果
- 系统会自动检测文件夹中的新图片
